# Лабораторная работа 3: каталог библиотечных книг

Каталог хранит книги с полями `book_id`, `title`, `category`, `year`, `author` и `isbn`.
Книги выдаются в том же порядке, в котором были добавлены. Поиск по категории и названию
не учитывает регистр. Поиск возвращает кортеж, поэтому нельзя добавить или удалить книгу
через результат поиска.

## Установка

Из корневой папки проекта выполните:

```bash
python -m pip install -e .
```

## Проверки

```bash
python -m pytest
ruff check .
python -m toolkit --help
```

## Пример использования

```python
from toolkit import Book, BookCatalog

catalog = BookCatalog()
book = Book("b1", "Хоббит", "Фэнтези", 1937, "Дж. Р. Р. Толкин", "9780000000001")
catalog.add(book)
print(catalog.get("b1"))
catalog.save("books.json")
```

JSON-файл содержит версию формата в поле `format_version`. При ошибке чтения каталог
не меняется: сначала проверяются все книги во временном словаре, и только после проверки
он становится содержимым каталога.
